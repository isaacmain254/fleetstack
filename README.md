# FleetStack

### Deploy JavaScript applications to any VPS with zero server configuration.

Build, deploy, and manage applications across any VPS or cloud provider through a modern web dashboard.

## Overview

FleetStack is an open-source deployment platform inspired by the developer experience of platforms like Vercel, while giving developers complete control over where their applications run.

Instead of deploying to a managed cloud, FleetStack allows you to deploy applications to your own infrastructure—whether that's AWS EC2, DigitalOcean, Hetzner, Oracle Cloud, or a server running in your home lab.

The goal is simple:

> Deploy JavaScript applications to any VPS with zero server configuration.

---

## Why FleetStack?

Deploying applications to a VPS usually involves:

- Installing Docker
- Configuring reverse proxies
- Managing SSL certificates
- Handling domains
- Setting up deployment pipelines
- Managing environment variables
- Monitoring server resources

FleetStack automates this entire workflow through a single dashboard.

## Vision

FleetStack aims to become a deployment platform that allows developers to:

- Own their infrastructure
- Deploy applications with one click
- Manage multiple servers from one dashboard
- Run on any cloud provider
- Stay completely open source
